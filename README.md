**Paletas de Hielo Bogota**
El proyecto consiste en el desarrollo de una plataforma web para una paletería especializada en la venta y distribución de paletas artesanales. La página está diseñada para facilitar la compra de productos tanto a clientes individuales como a empresas, organizadores de eventos y negocios que requieren pedidos al mayoreo.

🎯 1. Objetivo General
El objetivo de este proyecto es desarrollar una plataforma web para una paletería artesanal que resuelva la falta de un canal digital optimizado para la comercialización directa y al por mayor. El sistema busca solucionar la lentitud e ineficiencia en la gestión de pedidos de grandes volúmenes y cotizaciones para eventos, así como la limitada visibilidad del catálogo de productos, mediante una interfaz intuitiva, rápida y visualmente atractiva que permita a clientes individuales, empresas y organizadores explorar el menú completo, consultar promociones y realizar compras o solicitudes especiales de manera centralizada.

🌍 2. Contexto de Uso
La plataforma está dirigida a clientes particulares que desean adquirir paletas de forma individual, así como a empresas y negocios que requieren compras al por mayor. También está orientada a organizadores de eventos, escuelas, universidades, empresas de catering y organizadores de fiestas infantiles que buscan productos para sus celebraciones. Además, ofrece soluciones para empresas que realizan eventos corporativos y para cualquier persona interesada en contratar un servicio personalizado de paletas para bodas, cumpleaños, graduaciones, reuniones sociales y otras ocasiones especiales. 

📋 3. Requerimientos del Sistema
3.1 Requerimientos Funcionales
1. Visualización del catálogo de productos: El sistema debe permitir a los usuarios visualizar un catálogo de paletas y gelatinas organizado por categorías (Frutales, Cremosas, Especiales/Gourmet y Temporada), mostrando para cada producto una imagen, nombre, descripción, precio según su tamaño (grande o pequeño) y disponibilidad
2.Búsqueda y filtrado de productos : La plataforma debe permitir a los usuarios buscar productos mediante una barra de búsqueda y filtrarlos por categoría para facilitar la localización de las paletas o gelatinas deseadas.
3. Selección de cantidad y compra de productos: El sistema debe permitir al usuario seleccionar la cantidad de productos mediante controles de incremento y decremento, agregarlos al carrito de compras y generar pedidos tanto individuales como al por mayor.
4. Solicitud de cotización para eventos: La plataforma debe permitir que los usuarios soliciten una cotización para eventos a través de un formulario donde registren el tipo de evento, número de invitados, fecha, ubicación y datos de contacto.
5. Visualización de tipos de eventos: El sistema debe mostrar una sección con los servicios disponibles para diferentes tipos de eventos, como cumpleaños, bodas, eventos corporativos, graduaciones, fiestas infantiles y eventos sociales, incluyendo una breve descripción de cada servicio.
6.Galería de eventos realizados : La plataforma debe mostrar una galería de imágenes con eventos previamente atendidos por la empresa, permitiendo a los usuarios conocer los montajes, carritos de paletas y presentaciones disponibles.
7. Formulario de contacto : El sistema debe permitir que los usuarios envíen consultas, solicitudes o comentarios mediante un formulario que solicite nombre, correo electrónico, teléfono, tipo de evento y mensaje.
8. Gestión de usuarios administradores: El sistema debe permitir el acceso mediante autenticación a los administradores de la plataforma, garantizando que únicamente los usuarios autorizados puedan ingresar al panel de administración.
9. Gestión de pedidos :El sistema debe permitir al administrador visualizar un listado con todos los pedidos realizados por los clientes, mostrando información como el nombre del cliente, productos solicitados, cantidad, fecha, estado del pedido y total de la compra.
10. Actualización del estado de los pedidos El sistema debe permitir al administrador cambiar el estado de un pedido desde el panel de control. Al realizar la actualización, el sistema guardará los cambios directamente en la base de datos para que la información quede disponible en el historial de compras del cliente dentro de la plataforma.
11.  Gestión de cotizaciones para eventos La plataforma debe permitir al administrador visualizar las solicitudes de cotización de eventos recibidas (con detalles como tipo de evento, número de invitados, fecha, ubicación y datos de contacto), permitiéndole ingresar la respuesta con la propuesta económica y cambiar su estado (Pendiente, Cotizado, Aprobado, Rechazado) para su consulta en el sistema.
12.  Diseño adaptable La plataforma debe adaptarse correctamente a computadoras, tabletas y dispositivos móviles sin afectar la distribución de los elementos ni la funcionalidad de la página.
13.  Tiempo de respuesta La página debe cargar su contenido principal en un tiempo máximo de tres segundos bajo condiciones normales de conexión a Internet.
14.  Usabilidad La plataforma debe presentar una interfaz intuitiva con un menú de navegación visible, botones claramente identificados y una estructura que facilite el acceso al catálogo, eventos y formulario de contacto. 
15.  Seguridad de la información El sistema debe proteger los datos personales ingresados por los usuarios en los formularios de contacto y cotización mediante conexiones seguras (HTTPS) y almacenamiento adecuado de la información. 
16.  Solicitud de cotización para eventos  La plataforma debe permitir que los usuarios soliciten una cotización para eventos a través de un formulario donde registren el tipo de evento, número de invitados, fecha, ubicación y datos de contacto
17.  Compatibilidad La plataforma debe funcionar correctamente en los navegadores más utilizados, como Google Chrome, Microsoft Edge, Mozilla Firefox y Safari.
